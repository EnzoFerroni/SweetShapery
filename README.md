# SpatialSwiftUI

### O que está sendo testado

Esta POC testa diversos recursos disponíveis no visionOS, utilizando SwiftUI e RealityKit.

## Funcionalidades Principais:

### 1. Criação de Formas 3D (`CreateShapes.swift`)
Demonstra como criar formas primitivas 3D usando RealityKit

### 2. Efeitos Hover (`Hover.swift`)
Apresenta diferentes efeitos de hover disponíveis no visionOS

### 3. Offset Espacial (`Offset.swift`)
Demonstra o uso de offsets em 3D

### 4. Ornaments (`Ornament.swift`)
Controle completo de ornaments flutuantes

### 5. Rotação 3D (`Rotation3D.swift`)
Efeito de rotação em leque/carrossel

### 6. ZStack Espacial (`SpatialZStack.swift`)
Técnicas para criar profundidade em layouts

### 7. Tab Views (`WindowTabViews.swift`)
Interface com abas para navegação

### 8. Window Toolbars (`WindowToolbars.swift`)
Toolbar na parte inferior da janela (bottom ornament)
