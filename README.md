# Model3D

### O que está sendo testado

Esta POC testa a capacidade de carregar e interagir com modelos 3D no visionOS usando SwiftUI.

**Funcionalidades principais:**
- Carregamento de modelos 3D em USDZ com `Model3D`
- Rotação de objetos 3D com gestos de arrastar
- Gerenciamento de múltiplas janelas no visionOS
- Uso de ornaments para exibir informações em tempo real
